# DSA in Java – Part 13: Graphs (B)

This repository contains my Java implementations and problem-solving practice focused on **Advanced Graph Algorithms**, building upon fundamental graph concepts and traversal techniques.

## 📚 Topics Covered

- Topological Sorting
- Kahn's Algorithm
- Cycle Detection in Directed Graphs
- Shortest Path Algorithms
- Dijkstra's Algorithm
- Bellman-Ford Algorithm
- Prim's Algorithm
- Kruskal's Algorithm
- Minimum Spanning Tree (MST)
- Disjoint Set Union (DSU)
- Union-Find Algorithm
- Practice Problems Based on Graphs

## 🛠️ Technologies Used

- **Language:** Java
- **IDE:** VS Code
- **Concepts:** Graphs, BFS, DFS, Priority Queue, Greedy Algorithms, Union-Find

## 🎯 Learning Objectives

- Understand advanced graph algorithms.
- Implement shortest path algorithms.
- Learn Minimum Spanning Tree concepts.
- Understand topological sorting and cycle detection.
- Improve algorithmic thinking and problem-solving skills.

1. Clone the repository:

```bash
git clone https://github.com/Shivam33yadav/DSA-in-JAVA-Part-13-Graphs-B.git
```

2. Open the project in VS Code or any Java IDE.
